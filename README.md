# PEVESTORE

Tienda en línea de PEVESTORE (República Dominicana): productos personalizados con cotizador automático, servicios cotizables por WhatsApp, pago por transferencia y panel administrativo.

- Arquitectura y decisiones: [docs/ARQUITECTURA.md](docs/ARQUITECTURA.md)
- Publicación paso a paso: [docs/PUBLICACION.md](docs/PUBLICACION.md)
- Variables de entorno: copiar `.env.example` como `.env.local`

```bash
npm install
npm run dev
npm test
```
